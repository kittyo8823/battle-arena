# Battle Arena（仮題）

Card Trail のキャラ・敵・場所・曲を使った、生き残り型のアクション（ヴァンパイアサバイバー風）。`index.html` を開けば遊べる（1ファイル）。

- 7人のキャラ（それぞれ初めの武器が違う）・6つの場所（黒い森／沈没都市／地下の広間／密林の遺跡／機神の神殿／天上の聖堂）
- 武器9種・持ち物13種、レベルアップで選ぶ、宝箱で強化と進化、30分で死神
- 金貨で強化（ずっと残る）
- 最大4人のマルチ（部屋の番号で集まる）：https://kittyo8823.github.io/battle-arena/
- 作り方・確認は CLAUDE.md
